Documentación RTEMPUS
=====================

Documentación del sistema de monitoreo de tiempo de reacción RTEMPUS.
El sistema consta de un sistema embebido comunicado por BLE con un sensor inercial
Yost Labs 3-Space mini Bluetooth y una aplicación de escritorio que presenta el estimulo
y captura los datos dentro de archivos CSV.
